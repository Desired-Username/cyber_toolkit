Cyber Toolkit — Options

CVE, IP, domain, URL, email, and error code lookups use the following free public services, and need no key:
  • NVD — CVE details
  • RDAP — IP and domain registration info
  • ipwho.is — IP geolocation
  • Microsoft Learn — Microsoft/Windows error code search
  • MDN (Mozilla) — HTTP status code reference
  • man7.org — Linux/POSIX errno reference
  • Oracle Docs — Oracle database error code reference
  • Barracuda Central — IP reputation (DNS blocklist, no account exists to add a key for)
  • MXToolbox — email domain blacklist/MX check
  • urlscan.io — URL scan search (screenshot, behavior)
  • crt.sh — certificate transparency log search for a domain
  • SSL Labs (Qualys) — domain TLS/SSL configuration grade
  • Shodan InternetDB — IP exposure (open ports, hostnames, known CVEs)
  • Wayback Machine — archived-snapshot check for a domain or URL

Service API Keys

Reputation lookups for IP, domain, and file hashes work either way: without a key, they open that service's own public lookup page in a new tab; with a key added below, they instead show a richer summary right in the extension. Your key is sent only to the service provider over HTTPS when you run a lookup, is stored only in this browser profile, and is never logged. Once saved, it is only ever shown partially masked.

VirusTotal (optional)

Used for IP, domain, and file hash reputation. Free at virustotal.com (public API tier: ~4 requests/min, 500/day). Without a key, these open virustotal.com directly.

AbuseIPDB (optional)

Used for IP reputation (abuse confidence score, report history). Free at abuseipdb.com (free tier: 1,000 checks/day). Without a key, this opens abuseipdb.com directly.

abuse.ch (optional)

One free Auth-Key from auth.abuse.ch covers three separate lookups, all sharing this same key: URLhaus (domain reputation — known malware-distribution hosts), ThreatFox (IP/domain/hash IOC lookup), and MalwareBazaar (malware sample lookup by hash). Without a key, each opens its own public abuse.ch page directly instead.

GreyNoise Community (optional)

Used for IP reputation (internet background noise / scanner classification). Unlike the others above, GreyNoise's Community lookup already works with no key at all — adding one (free at greynoise.io) just raises the rate limit.

EmailRep.io (required)

Used for email address reputation (malicious activity, breach exposure, disposable-address detection). Unlike the other services here, EmailRep.io has no public webpage to fall back to — a key is required for any result, not just for a richer one. See github.com/sublime-security/emailrep.io for how to request a free key.
