Cyber Toolkit — Privacy Policy

Last updated: 27 August 2026

Cyber Toolkit is a browser extension that adds right-click lookups for security and OSINT indicators (CVE IDs, IP addresses, domains, URLs, file hashes, and email addresses). This page explains what data the extension handles and where it goes.

We (the developer) do not collect anything

Cyber Toolkit has no server of its own, no analytics, and no tracking. Nothing you select, type, or configure in the extension is ever sent to us. We have no way to see how you use it.

What the extension sends, and to whom

When you right-click selected text or a link and choose a lookup, the extension sends only that selected text (or link) to the one third-party service you chose, directly from your browser, over HTTPS. Nothing is sent in the background or without you explicitly choosing a lookup. Depending on which lookup you pick, that may be one of:

  • National Vulnerability Database (NVD) — CVE details
  • RDAP (rdap.org) and ipwho.is — IP/domain registration info and geolocation
  • VirusTotal, AbuseIPDB, GreyNoise, Barracuda Central, ThreatFox — IP/domain reputation
  • URLhaus, MalwareBazaar — domain/file-hash threat intelligence
  • crt.sh, SSL Labs, Shodan InternetDB, Wayback Machine — domain/IP recon
  • urlscan.io — URL scan history
  • MXToolbox, EmailRep.io — email/domain checks
  • Microsoft Learn, MDN, man7.org, Oracle Docs — error code references

Each of these is a separate, independent service with its own privacy policy governing what it does with a query it receives. Cyber Toolkit does not control or see their responses beyond displaying them to you.

Optional API keys

Some services (VirusTotal, AbuseIPDB, GreyNoise, abuse.ch, EmailRep.io) support an optional API key you can add in the extension's Options page for richer results. If you add one:

  • It is stored only in your browser's local extension storage (chrome.storage.local).
  • It is sent only to the specific service it belongs to, only when you run that lookup.
  • It is never sent to us, logged, or shown anywhere in full once saved (only partially masked).
  • You can remove it at any time from the Options page.

Local storage

The extension uses browser storage for two purposes only: saving any API keys you choose to add (as above), and briefly holding a lookup's result so it can be displayed on the results page you're shown after clicking a menu item. Nothing here syncs to an account or leaves your browser except the queries described above.

Changes to this policy

If this policy changes, the "Last updated" date above will change accordingly.
